# Input and Output Operations

## Overview

This directory contains C programming exercises demonstrating standard input and output operations using the C Standard I/O library.

## Topics Covered

- `printf()` – Formatted output operations.
- `scanf()` – Formatted input operations.
- Format specifiers.
- Reading user input.
- Displaying program output.

## Objective

To understand and implement fundamental input and output operations in C through practical programming exercises.
