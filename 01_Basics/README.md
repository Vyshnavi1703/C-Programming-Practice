# C Programming – Basics

## Overview

This directory contains fundamental C programming exercises designed to develop a strong understanding of basic programming concepts and syntax.

## Topics Covered

- Basic program structure
- Variables and data types
- Input and output operations
- Arithmetic operators
- Relational and logical operators
- Assignment and increment/decrement operators
- Type conversion and expressions

## Objective

To build a strong foundation in C programming through practical implementation and problem-solving exercises.
