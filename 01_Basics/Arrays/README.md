# C Programming – Arrays

## Overview

This directory contains C programming exercises focused on array declaration, initialization, traversal, and manipulation.

## Topics Covered

- One-dimensional arrays
- Two-dimensional arrays
- Array input and output
- Array traversal
- Searching and sorting elements
- Finding maximum and minimum elements
- Sum and average of array elements
- Array manipulation techniques

## Objective

To develop problem-solving skills and understand how arrays are used to store, access, and process collections of data in C programming.
