# C Data Types

## Overview

This directory contains C programming exercises focused on understanding and implementing fundamental data types and variable declarations.

## Topics Covered

- Basic data types: `int`, `char`, `float`, and `double`
- Variable declaration and initialization
- Data type sizes using `sizeof()`
- Format specifiers
- Type modifiers: `short`, `long`, `signed`, and `unsigned`
- Type conversion and casting

## Objective

To understand the representation, declaration, initialization, and usage of data types in C programming through practical exercises.
