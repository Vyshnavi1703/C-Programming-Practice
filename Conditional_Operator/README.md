# C Programming – Conditional Operator

## Overview
This directory contains C programming exercises focused on using the conditional (ternary) operator to perform decision-making operations.

## Topics Covered
- Conditional operator (`?:`)
- Syntax and usage
- Finding the largest of two numbers
- Finding the largest of three numbers
- Checking even or odd numbers
- Positive, negative, or zero identification
- Nested conditional operators
- Conditional expressions

## Objective
To understand and implement decision-making logic using the conditional operator in C programming.
