# C Programming – Pointers

## Overview
This directory contains C programming exercises focused on understanding pointers, memory addresses, and pointer operations.

## Topics Covered
- Pointer declaration and initialization
- Address-of (`&`) and dereference (`*`) operators
- Pointer arithmetic
- Pointers and arrays
- Pointers and strings
- Pointers and functions
- Pointer to pointer
- NULL pointers
- Void pointers
- Dynamic memory allocation

## Objective
To develop a strong understanding of pointer concepts and memory handling in C through practical programming exercises.
