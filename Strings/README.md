# C Programming – Strings

## Overview

This directory contains C programming exercises focused on string handling, character arrays, and string manipulation in C.

## Topics Covered

- String declaration and initialization
- String input and output
- Character arrays
- String traversal and manipulation
- String length calculation
- String comparison
- String copying and concatenation
- Reversing a string
- Palindrome string checking
- String handling without standard library functions

## Objective

To develop a practical understanding of string representation and manipulation in C through programming exercises and problem-solving techniques.
