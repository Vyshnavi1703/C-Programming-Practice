# C Programming Practice

## Overview
This repository contains a collection of C programming exercises covering fundamental programming concepts and problem-solving techniques. It is intended to strengthen programming skills through practical implementation.

## Topics Covered

### 1. Basics
- Introduction to C programming
- Variables and constants
- Data types
- Operators and expressions
- Type conversion

### 2. Conditional Operator
- Conditional (ternary) operator
- Nested conditional expressions
- Decision-making using conditional expressions

### 3. Arrays
- One-dimensional arrays
- Two-dimensional arrays
- Array traversal
- Searching and sorting
- Array operations

### 4. Strings
- String declaration and initialization
- String input and output
- String manipulation
- String length and comparison
- String reversal and palindrome checking

### 5. Functions
- Function declaration and definition
- Function calling
- Function arguments and return values
- User-defined functions

### 6. Input and Output
- `printf()` – Formatted output
- `scanf()` – Formatted input
- Format specifiers
- Reading and displaying user input

### 7. Pointers
- Pointer declaration and initialization
- Address-of and dereference operators
- Pointer arithmetic
- Pointers and arrays
- Pointers and functions

## Objective
To develop a strong foundation in C programming through hands-on coding, logical problem-solving, and practical implementation of programming concepts.

## Programming Language
- C

## Repository Purpose
This repository serves as a personal programming practice portfolio, showcasing C programming knowledge, coding skills, and continuous learning.
